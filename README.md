# আজকের খরচ (Ajker Khoroch)

রোজ জানুন আজ কত টাকা নিশ্চিন্তে খরচ করা যায়। বাংলা ও ইংরেজিতে, লগইন ছাড়া।
A free daily budget app: see how much you can safely spend today. Bengali and English, no login.

অ্যাপ / App: https://pappa6.github.io/ajker-khoroch/

**গোপনীয়তা:** অ্যাপে কোনো সার্ভার বা ডেটাবেস নেই। ব্যবহারকারীর লেখা সব তথ্য শুধু তাঁর নিজের ফোনের ব্রাউজারে থাকে, কোথাও পাঠানো হয় না।

**Privacy:** The app has no server or database. Everything a user enters stays only in their own phone's browser and is never sent anywhere.

## স্টেটমেন্ট ও হিসাবের নিয়ম / How statements are counted

- ব্যাংক স্টেটমেন্টই মূল হিসাব; PhonePe/GPay-র স্টেটমেন্ট তার অংশ। একই UPI রেফারেন্স (UTR) একবারই গোনা হয়; রেফারেন্স না থাকলে একই টাকা ±১ দিনে অন্য উৎসে মিললে একটাই ধরা হয়।
- একক ও জয়েন্ট অ্যাকাউন্ট আলাদা নামে রাখা যায়; নিজের দুই অ্যাকাউন্টের মধ্যে টাকা সরানো খরচ নয়।
- FD/RD/SIP/সোনা/শেয়ার সঞ্চয় হিসেবে দেখায়, খরচ হিসেবে নয়। ক্রেডিট কার্ডের বিল একবার গোনা হয়। ATM-এর টাকা বাদ, নগদ খরচ হাতে লিখুন।
- যে লাইন নিশ্চিতভাবে পড়া যায়নি বা ব্যালেন্সের সঙ্গে মেলেনি, তা চুপচাপ বাদ যায় না; লাল সতর্কতায় দেখায়।
- দিন/সপ্তাহ/মাস/ত্রৈমাসিক/ষান্মাসিক হিসাবে চার্ট, সব লেনদেনের সার্চ, ও উপদেষ্টা।
